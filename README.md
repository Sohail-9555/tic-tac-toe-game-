# Tic ♥ Toe

A playful, browser-based Tic Tac Toe game for local multiplayer matches. Play with two or three people on one screen, pick your markers, and keep score across rounds.

## Features

- Local multiplayer for **2 or 3 players**
- Each player selects a unique **X**, **O**, or **♥** marker
- Turn rotation, win detection, and draw detection
- Live scoreboard for every player
- Start a new round without losing match scores
- Start a new match to reset the scoreboard
- Soft 3D marker styling and pop-in move animations
- Responsive layout for desktop and mobile browsers

## Play locally

No installation is required.

1. Download or clone this repository.
2. Open [index.html](index.html) in any modern web browser.
3. Choose the number of players and assign markers.
4. Select **Start game** and take turns placing markers.

## How to win

Get three of your own markers in a horizontal, vertical, or diagonal row. In a three-player game, turns rotate between all selected players.
